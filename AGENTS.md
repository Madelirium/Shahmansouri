# Istruzioni condivise del progetto

Prima di intervenire leggere `DA_NON_PUBBLICARE/organizzazione/MEMORIA.md` e `DA_NON_PUBBLICARE/organizzazione/CHAT.md`. Controllare lo stato attuale dei file interessati e le istruzioni locali applicabili.

La memoria su disco è il punto di passaggio tra chat. Aggiornarla alla conclusione di un incarico o dopo una decisione rilevante, indicando data, file coinvolti, controlli eseguiti e stato locale o pubblicato. Registrare come approvate soltanto decisioni effettivamente accettate dal proprietario. Le proposte restano proposte.

Prima di modificare file dichiarare nella sezione Attività della memoria l'incarico, la chat responsabile e i file riservati. Rileggere la sezione prima di scrivere. Se un file risulta occupato, coordinarsi con la chat responsabile. Questa convenzione richiede coordinamento esplicito e non costituisce un blocco automatico. Evitare scritture simultanee anche sulla memoria stessa, usare un unico responsabile durante lavori paralleli.

Usare agenti temporanei per attività indipendenti quando serve. Assegnare ambiti e file disgiunti. La chat che delega integra i risultati e verifica il comportamento finale. Le chat dedicate condividono gli stessi file locali.

Preservare modifiche esistenti. Non dedurre la pubblicazione dalla presenza di file locali, CNAME o sitemap. Conservare audit e backup in DA_NON_PUBBLICARE. Escludere istruzioni e memoria dai pacchetti pubblicati. Verificare il processo di distribuzione prima di pubblicare.

Questa cartella al 17 novembre 2026 non è riconosciuta come repository Git. Non inizializzare repository, creare worktree o ripristinare file automaticamente.
